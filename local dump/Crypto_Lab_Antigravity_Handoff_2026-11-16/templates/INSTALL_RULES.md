# Installing the templates

These templates are not active merely because the ZIP was extracted. Review existing
AGENTS.md, GEMINI.md and inherited .agents rules first. Use Antigravity's supported
workspace Customizations > Rules interface, or copy only the three immediate Markdown
files to the appropriate workspace-root `.agents/rules/` after the takeover amendment.

Do not overwrite product instructions blindly. Verify the installed application discovers
the files and that their effective instructions are consistent. Rules are prompt guidance,
not an operating-system security boundary. Do not place the whole historical archive in
an always-on rule; link to source files and read the relevant ones on demand.

Current format source: https://antigravity.google/docs/rules/ (checked 2026-11-16).
