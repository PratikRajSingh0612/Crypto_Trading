# Provenance and completeness limits

## What this replacement is

The original Deep Research report/ZIP was not exposed as an accessible conversation attachment. Searching conversation files found only the older Claude prompt archive and October context archive. The replacement is newly authored in this chat; it must not be passed off as the original report.

Public repository files and branch metadata were inspected through the GitHub connector on 16 November 2026. The raw repository archive could not be downloaded into this runtime. Several older uploaded source documents were listed by file ID but their backing content could not be materialized. Their absence is recorded, not concealed with a placeholder bearing the original title.

## Included verbatim material

`sources/history/` contains the available mounted historical text reports, unchanged.
`sources/legacy/` contains the available October handoff/prompt documents, unchanged and explicitly historical. Their operating instructions are superseded by the owner's Antigravity-only direction.
`sources/remote_snapshot.json` records the connector-returned branch identities, not a live local Git inspection.
`sources/source_map.json` identifies controlling repository paths and how they were inspected or must be inspected locally.

## Not included or not independently established

- The blocked Deep Research report and its original ZIP.
- A verbatim export of every message in the very long conversation; skipped/hidden messages are not reconstructed.
- A full downloadable copy of the product repository or its Git history.
- Full latest versions of every specification and plan. The original files must be read from the user's existing repository; the collector can copy them locally.
- Private controller journals, policy files, credentials or ignored evidence that were never uploaded.
- Current local main, uncommitted changes, process ownership, latest verifier outcomes or installed packages on the user's Windows machine.
- Passing tests performed by this assistant on the Windows product. Reported passes are source/commit claims, not reruns.
- Acceptance of later tasks solely because a plan or environment exists.

## How to close the source gap without rebuilding anything

Antigravity must read the real local repository and preserved journals first. `tools/collect_local_context.py` can produce a separate local snapshot of selected tracked documentation and exact plan heading indexes using read-only Git commands. It does not implement, install, test or publish anything. Review it before use. It was syntax-checked and tested on a disposable repository here, not executed on the user's Windows checkout.

The full accepted product specification and current task plan outrank a reconstructed summary for product behavior. The owner's latest migration direction changes the development process, not historical evidence or unverified completion status. Record precise procedural amendments instead of silently pretending old controller-dependent clauses are satisfied.

## Review coverage

The handoff summaries are based on the visible conversation, inspected historical package documents, selected current repository clauses and actual branch/commit metadata. Bundling a long historical report is not a claim that every assertion in it was independently audited. The original available text is retained so Antigravity can inspect the controlling detail on demand.
