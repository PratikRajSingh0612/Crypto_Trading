# Crypto Lab - Autonomous Delivery Prompt Package

Version 1.0 | Prepared 2026-10-31 | Plain-text prompts, not an executable agent or plugin

## Purpose

Give Claude Code one standing assignment for the entire local seven-engine research lab. Let it plan the next milestone from the actual repository, implement, test, review, fix, document, commit and publish without asking for routine permission after each task. Preserve real product decisions, tool permissions and verification gates.

This package does not implement the product. It does not install skills, modify Claude settings, launch a process, grant tool access, promise continuous background execution, or change GitHub. The user adopts its delegation policy by pasting START_CLAUDE.txt. New product-specific implementation plans are still required just in time.

## What changes about the workflow

The new delegation replaces repeated requests to continue routine in-scope work, artificial one-correction-pass limits, and asking for a fresh prompt after every accepted task. It does NOT replace product safety rules, scope-specific ownership, actual permission prompts, independent review or evidence of completion.

The whole thirteen-project destination stays on the backlog. Project 1 remains fake-adapter-only until accepted. Later projects activate their own narrowly described capabilities only after prerequisites and their reviewed specifications exist. Do not import later engines, market-data clients or UI into Project 1 to save time.

## What still needs a human

- Existing foreground, complete-verifier launches, until a separately approved execution change genuinely removes that constraint.
- Exact dependency/interpreter/model acquisitions not already authorized.
- Material unresolved product/architecture choices, costs, licensing terms or access the agent cannot resolve within the approved scope.
- A mandatory point-of-use approval required by an installed skill or managed tool policy.

Do not disable safeguards to turn these into unattended actions. Batch related decisions into one compact request; do not ask about questions answered by the repository.
